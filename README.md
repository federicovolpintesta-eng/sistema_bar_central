> **Dashboard analítico y sistema integral automatizado para la gestión del Bar Central.**

## ✨ Características Principales
- **Dashboard Premium**: Interfaz visual y analítica para monitoreo de métricas, catálogos de productos e historial.
- **Flujos Automatizados**: Integración directa con **n8n** (`n8n_workflow_bar_central.json`) para procesar datos sin intervención manual.
- **Sincronización con Google Sheets**: Documentación y código orientado a consumir catálogos en vivo y volcar reportes automáticos en hojas de cálculo.

## 🛠️ Tecnologías Utilizadas
- **Node.js** (Servidor de Backend, Express)
- **n8n** (Automatización de flujos de trabajo)
- **HTML/CSS/JS** (Dashboard Frontend Premium)
- **Integraciones**: Google Sheets API.
